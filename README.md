# better-prompt

A Claude skill that turns a rough prompt into the strongest prompt for reaching the goal behind it,
following Anthropic's current prompting and Claude Code project-building guidance.

`SKILL.md` and `references/` here are the latest version. They're updated automatically whenever a
change passes a blind A/B evaluation (see `VERSION`). The claude.ai loader skill fetches these files
each time it runs, so the uploaded skill never needs re-uploading.
